# ABI-187 Full-Spectral BTD+SZA Signed-Detail Full-Scale Skip ASPP Line-Aux Focal-Tversky Centerline Auxiliary v1

Controlled family-development continuation of the ABI-183/ABI-184 signed-detail full-scale skip ASPP branch. The model architecture, provider-approved `abi_16ch_plus_sza` input, deterministic approved-channel BTD features, signed local/mid-scale detail streams, ASPP bottleneck, full-scale skip fusion, Line Target auxiliary head at weight 0.01, Centerline Target auxiliary head at weight 0.02, combined source-balanced traversal, trusted random mirroring, AdamW learning rate, batch size, constant scheduler, disabled early stopping, and trusted capped-record policy remain unchanged.

The hypothesis is that direct Line plus Centerline supervision and the signed-detail architecture may constrain focal-Tversky recall expansion enough to recover ABI-184 fixed-threshold recall and MIT-positive weakness without losing all of its connected line behavior. Candidate code owns only the PyTorch model over provider-supplied tensors and does not implement data loading, sampling, augmentation, target derivation, losses, metrics, thresholding, Artifact Filters, postprocessing, resource placement, or lifecycle behavior.
