# ABI-290 temporal attention precision-gated continuity U-Net

ABI-290 is a mechanism-changing temporal-family continuation after ABI-289. ABI-289 showed that separating center-detail recall evidence and directional continuity evidence can raise fixed-threshold recall, but its late non-negative lift broadened predictions and lost precision, source balance, and connected-line organization. ABI-290 keeps the same provider-owned temporal-attention backbone and replaces the permissive lift with a precision-gated continuity lift plus a tiny learned clutter-veto residual initialized nearly inactive.

The model consumes only provider-owned `abi_16ch_plus_sza_temporal` inputs with offsets `[-1, 0, 1]` and trusted `temporal_eligible_center` selection. It builds per-frame ABI/SZA/BTD features, fuses frames with temporal attention/change evidence, decodes with ASPP and high-resolution directional context, then keeps center-detail recall and continuity features separate until the final differentiable head. The primary mask logits come from the recall path, the continuity lift is allowed only through learned recall/continuity agreement, and line/centerline auxiliary outputs remain tied to trusted provider-derived targets.

Hypothesis: precision-gating the late continuity lift can preserve ABI-289's recall benefit while recovering cleaner precision, source balance, and connected-line support closer to ABI-238/223/285, without Candidate-owned thresholds, postprocessing, Artifact Filters, losses, metrics, data loading, temporal lookup, sample selection, coordinates, or resource scheduling.

This is an exploratory/default-budget Candidate, not a promotion claim. Candidate code remains architecture-only and does not implement thresholds, morphology, postprocessing, Artifact Filters, metrics, losses, data loading, temporal lookup, frame repair/padding, sample selection, target derivation, coordinates, Dataset Source identity, downloads, resource scheduling, prediction retention, or lifecycle behavior.
