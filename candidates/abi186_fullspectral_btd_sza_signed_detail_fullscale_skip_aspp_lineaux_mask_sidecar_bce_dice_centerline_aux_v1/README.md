# ABI-186 Full-Spectral BTD+SZA Signed-Detail Full-Scale Skip ASPP Line-Aux Mask-Sidecar BCE-Dice Centerline Auxiliary v1

ABI-186 is an exploratory family-development continuation of ABI-184/185. It keeps the provider-approved `abi_16ch_plus_sza` input, normalized ABI channels 1-16, deterministic approved-channel thermal BTD features, Solar Geometry Input, signed-detail full-scale skip ASPP decoder, BCE-Dice primary loss, trusted Line Target auxiliary supervision at weight 0.01, trusted Centerline Target auxiliary supervision at weight 0.02, combined source-balanced traversal, trusted random mirroring, AdamW learning rate `0.0003`, batch size 4, manifest max epochs 12, constant learning rate, and disabled early stopping.

The research change is a neutral-initialized, low-capacity additive `MaskRecallSidecar` attached only to `mask_logits`. The Line and Centerline auxiliary heads still read the original refined features, so the sidecar is intended to improve fixed-threshold recall/calibration without perturbing ABI-184's line-connected auxiliary representation or implementing candidate-owned thresholding, postprocessing, losses, sampling, augmentation, Artifact Filters, coordinates, resource placement, or lifecycle control.
