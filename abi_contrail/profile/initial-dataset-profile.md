# GOES ABI Dataset Profile and Agent Campaign Context

## Provenance

- artifact type: Dataset Profile Artifact generation instructions
- dataset profile schema: `dataset-profile.v1`
- campaign context schema: `abi_agent_campaign_context/v1`
- research problem: `goes_abi_contrail_segmentation` version `v0`
- generator versions: `abi_contrail.profile.v1` and `abi_contrail.campaign_context.v1`
- dataset identity: ABI Patches from the MIT and Google Dataset Sources
- split scope: Google source provenance plus MIT deterministic whole-scene splitting before windowing
- source policy: generated by trusted Research Problem provider code outside the Agent Control Boundary

The required generated artifact is `agent-campaign-context.v1.json` beside this document. It is a curated, reproducible summary for candidate design, not raw data and not a new authoritative Run Result.

## Covered summaries

The generated JSON contains:

- exact mounted-snapshot MIT and Google train/validation counts;
- positive ABI Patch prevalence and Contrail Mask area histograms, including per-split distributions;
- ABI channels 1-16 names, wavelengths, units, and bounded deterministic safe-range statistics;
- input/label shapes, dtypes, chunks, split policy, record digests, and projection caveats;
- canonical MCAST 1.1 and 2.1 raw, Artifact-Filtered, and Dataset Source-stratified Dice, precision, recall, and Contrail Connectivity metrics;
- threshold optima and precision/recall balance summaries;
- ordered Artifact Filter configuration, removed-pixel effects, registry identity, and input checksums;
- bounded ABI-025 manual canary Run, Post-Run Evaluation, and human-review context.

Channel statistics deterministically select at most 16 records per split and 1,024 evenly spaced pixels per selected record. Non-finite values are counted but excluded from ranges. Coordinate source indices 16 and 17 are never sampled by the channel-statistics implementation.

## Trusted generation and refresh

Run from the outer trusted Research Problem workspace. Do not run this command inside the Agent Control Boundary and do not invoke candidate code or model training.

```bash
RUN_ROOT=/data/iross/abi-ml-autoresearch/runs/run_20260810_110532_b465cf
uv run abi-campaign-context \
  --workspace-config ml-autoresearch.toml \
  --run "$RUN_ROOT" \
  --evaluation "$RUN_ROOT/outputs/evaluations/eval_20260810_110644_c0d61d" \
  --output abi_contrail/profile/agent-campaign-context.v1.json
```

The command loads named roots from the Workspace Configuration, verifies the self-contained canonical MCAST registry and referenced checksums, validates ABI-025 Run/Evaluation/acceptance-report linkage, generates dataset summaries, applies the safety contract, writes atomically, and reloads the result.

The lower-level dataset-only generator remains available for fixture work:

```bash
uv run python -m abi_contrail.profile \
  --data-config <CONFIG_JSON> \
  --output <OUTPUT_JSON>
```

`--allow-missing` may produce a documented placeholder only for scaffolding; it must not replace the required campaign artifact.

## Operator review checklist

After each refresh:

1. Run focused and full tests.
2. Confirm the generated file passes `load_agent_campaign_context` validation.
3. Search the JSON for absolute host paths, model-weight suffixes, unrestricted roots, and individual scene identifiers.
4. Confirm source channel indices included are exactly 0-15 and excluded are 16-17.
5. Confirm registry id `abi-mcast-working-validation-v1`, both MCAST versions, Run id, Evaluation id, and checksums match reviewed source artifacts.
6. Run `prepare-agent-boundary`, confirm the JSON is indexed and copied read-only, and confirm training, ancillary, and baselines roots remain unmounted.

## Safety and limitations

- No raw training samples, qualitative pixel examples, longitude/latitude arrays or statistics, model weights, prediction rasters, per-sample metrics, or unrestricted artifact references are serialized.
- Candidate code does not own generation, data loading, split logic, losses, metrics, Artifact Filters, Baseline Segmenter loading, or sampling.
- Bounded channel ranges characterize the selected snapshot sample, not absolute physical validity limits.
- Contrail Mask histograms summarize binary `labels != 0`; they do not expose instance layers.
- MCAST and ABI-025 values remain summaries of their identified immutable source artifacts. Promotion remains a separate human decision.
